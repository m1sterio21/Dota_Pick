DOTA PICK — подсказка героя на драфте (пабы 7000+, Dota2ProTracker + STRATZ + OpenDota)

1. Распакуй архив в любую папку (например, на рабочий стол).
2. Запусти «Запуск.bat».
   - Если Python не установлен, он поставится сам: скачается с официального сайта python.org
     и установится только для твоего пользователя Windows (без прав администратора). 1-3 минуты.
   - При первом запуске программа сама доставит нужные библиотеки (окошко «устанавливаю библиотеки»).
   - Если Windows спросит про запуск файла из интернета — разреши.
3. В окне нажми ⚙ и впиши СВОЙ Steam ID (Friend ID из Доты), нажми ⟳.
4. По желанию: «Токен STRATZ, веса, клавиша…» → вставь СВОЙ токен со stratz.com/api.
5. В Доте поставь «Окно без рамки». На драфте жми Scroll Lock — программа сама найдёт героев
   (ищет драфт на всех мониторах).

- Левый клик по герою — пояснение, правый клик — «Показать сборку».
- Клик по заголовку колонки — сортировка, повторный клик — обычный порядок.

Программа не трогает файлы и память Доты — только делает скриншот экрана.
Если что-то не так с распознаванием — пришли файлы из папки screens: last.png и last_debug.png.
