# Dota Pick

Подсказывает лучшего героя под текущий драфт (рейтинг, All Pick) по статистике STRATZ + OpenDota
и твоей личной статистике.

**С игрой не взаимодействует:** не читает и не меняет файлы Доты, не лезет в память процесса,
не нажимает клавиши. Только делает скриншот экрана (как OBS/Discord) и распознаёт его.

## Запуск

Дважды кликнуть `Запуск.bat`.

1. Вписать Steam ID (Friend ID из Доты, Steam64 или ссылку на профиль stratz/dotabuff) → «Загрузить».
2. **Настройки → токен STRATZ** (бесплатно: https://stratz.com/api, войти через Steam, скопировать токен).
   Без токена работает только OpenDota: позиции примерные, матчапы по маленькой выборке.
3. Выбрать позицию 1–5 и сторону (Свет/Тьма — в драфте видно, слева ты или справа).
4. В драфте нажать **Scroll Lock** — программа заскринит экран, найдёт героев и выдаст топ.
   Нераспознанных героев и баны можно вписать вручную.

Дота должна быть в режиме **«Окно без рамки»** (Borderless) — в полноэкранном режиме скриншот бывает чёрным.
Окно программы удобно держать на втором мониторе.

## Как считается оценка (в п.п. винрейта)

Вся статистика — с хай-ммр, а не с твоего ранга: **Dota2ProTracker (пабы 7000+)** основной источник,
STRATZ и OpenDota (Divine/Immortal) — дополнительные.

- **Мета** — рейтинг протрекера /100 на твоей позиции (учитывает и винрейт, и сколько героя играют)
  + винрейт со сглаживанием: при малом числе матчей он тянется к 50%.
- **Контрпик** — сумма преимуществ против каждого вражеского героя (протрекер 60%, STRATZ 30%, OpenDota 10%).
- **Синергия** — сумма синергий с уже выбранными союзниками (протрекер + STRATZ).
- В список попадают только герои, которых на 7000+ реально играют на выбранной позиции
  (плюс твои коронные, если у тебя на них 30+ игр).
- **Комфорт** — сколько у тебя рейтинговых игр на герое, твой винрейт на нём, играл ли недавно.

Веса меняются в настройках. Статистика кэшируется в `cache/` и обновляется раз в сутки
(или кнопкой «Обновить статистику»).

## Если распознаёт плохо

Последний скриншот и картинка с рамками распознанного лежат в `screens/last.png` и `screens/last_debug.png`.
Проверка на любом скрине: `python -m dotapick.recognize screens/last.png`.
